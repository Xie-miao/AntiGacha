# 原神 & 星铁养成期望计算工具 AntiGacha

本工具用于计算原神圣遗物与崩坏：星穹铁道遗器在刷取过程中的概率期望，帮助玩家合理规划体力消耗。

---

## 1. 核心概念说明

* **单件胚子掉落概率** 指在获得单件五星圣遗物（遗器）的条件下，该产出同时满足以下条件的联合概率：
    * 特定套装
    * 特定部位
    * 特定主属性
    * 初始副词条包含目标词条情况

* **单件满级词条分布概率** 指在确定套装、部位及主属性的前提下，强化至满级（+20 / +15）后，该件装备所含**有效副词条总数**（初始词条数 + 强化提升次数）的离散概率分布。

* **套装满级词条分布概率** 指全身多个部位有效词条数之和的综合分布。本工具通过对各部位概率分布进行**卷积计算**得出，用于评估达成套装总目标的难易程度。

* **期望天数** 基于每日自然回复体力所折算的产出期望：
    * **原神：** 约 180 树脂/日（折合 9 件五星圣遗物）
    * **星铁：** 约 240 开拓力/日（折合 12 件五星遗器）
    * **计算公式：** $$E = \frac{1}{\text{每日产出数量} \times \text{目标综合概率}}$$

---

## 2. 计算原理

* **概率公式** 计算逻辑：`获得该套装概率` $\times$ `获得该部位概率` $\times$ `获得所选主属性概率` $\times$ `副词条生成匹配概率` $\times$ `强化命中概率`。
* **权重系统** 根据大佬们的数据，不同主副词条的权重不同（如防御力权重远高于双暴）。本工具采用社区实测权重进行计算。
* **蒙特卡洛模拟** 由于副词条生成逻辑需排除主词条且遵循权重随机抽取，逻辑较为复杂，本工具通过 **200,000 次**大规模随机模拟来逼近真实掉落分布。
* **强化计算** 由于强化时各词条提升概率均等，强化概率采用**二项分布**公式进行计算，模拟 5 次强化机会落在有效词条上的分布情况。
